# Mythbound: ChatGPT Creature Prompts

_Generated by `tools/build_roster.py`._

**How to use:** paste the Style Lock (in `ART_LIST.md`) once at the start of a ChatGPT chat. Then send ONE evolution-sheet prompt per message. Generating the whole line in one image keeps the 5 stages looking like the same creature. Crop each stage out afterwards, then ask for the back view of each (prompt at the bottom of each line).
