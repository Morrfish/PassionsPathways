Publish to Spotify, Apple Podcasts and more

Every podcast app reads one file: an RSS feed. Put your MP3s, cover and feed on the web, then give the feed's address to each app once. New episodes show up on their own after that.

Steps

  1. Make an MP3 for each episode in step 3.
  2. Download the publish kit. It has feed.xml, cover.jpg, every MP3, scripts and show notes.
  3. Upload the files to the web folder you typed above (a GitHub Pages folder works, as do Google Cloud, Dropbox-style hosts or any web host).
  4. Open the feed address in a browser to check it loads: …/feed.xml
  5. Submit that address once at Spotify for Creators and Apple Podcasts Connect. YouTube Music, Amazon Music, Pocket Casts and others take the same feed.

Clone my voice

    
Record 1 to 3 minutes of yourself reading in a quiet room, about a hand's width from the mic. More clean audio makes a more lifelike voice. Talk the way you would on the show.
