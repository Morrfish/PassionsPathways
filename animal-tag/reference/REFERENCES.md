# Wild Tag — reference images needed

These images are used to build the 3D models in Blender. Put the files in this folder (`animal-tag/reference/`).

**Format for every image:** PNG, plain background (white or gray), whole creature in frame, standing in a neutral pose, no text on the picture. Name each file after the item, e.g. `gorilla_front.png`.

## 1. Style guide (send this first)
- **One sheet showing 3–4 animals side by side in the final art style.** Every model will match this, so the look stays consistent. Say whether you want chunky low-poly, cute and round, or something else.

## What to send first
The style guide plus the Gorilla and the Dragon. Those two get modeled and put in the game first so the look can be checked. Once it's right, send the rest in batches.

Any "more stuff" (new animals, maps, modes and so on) can come as a plain text list along with the images.
