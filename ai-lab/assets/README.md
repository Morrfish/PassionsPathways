# assets/

Drop art here and the lab uses it automatically. Nothing breaks if a file is missing; the lab draws its own simple creatures and robot instead.

Files that work the moment you add them (exact names, PNG with transparent background):

    assets/species/zorb_body.png      assets/species/quib_body.png      assets/species/flonk_body.png
    assets/species/zorb_body_s.png    ... _m.png   ... _l.png   (optional short / medium / tall versions; same for quib and flonk)
    assets/mascot/nibble_think.png    assets/mascot/nibble_oops.png

See IMAGE_LIST.md in the main folder for sizes, style notes, and everything else.
